## Risks observed this review

1. **`SUMO_HOME` is set in the review shell** to a macOS Framework install
   (`/Library/Frameworks/EclipseSUMO.framework/...1.27.1`) — exactly the footgun CLAUDE.md's
   Environment section calls out by name. It happens to be harmless today only because that
   Framework build is coincidentally also 1.27.1 (`sumo --version` on PATH still resolves to
   1.27.1 and all 482 tests pass), but it is not unset as the project's own conventions require,
   and a future SUMO upgrade on either side would silently reintroduce version drift with no test
   currently positioned to catch it except the one that checks PATH, not `SUMO_HOME`. Cheap fix:
   unset it in the shell profile used for this work.
2. **Three untracked docs files** sit in `git status`
   (`docs/agent_communication_diagram.md`, `docs/class_diagram.md`, `docs/study_flow_diagram.md`)
   — not part of any tracked task's output and left out of this review's commit on purpose (the
   skill's scope is the tracker + this file). Worth a deliberate commit or a `.gitignore` decision
   next session rather than leaving them to accumulate as "mystery untracked files" for a future
   review to puzzle over.
3. **Sustainability, still.** This is the third consecutive review (13, 14, 15 Sep) recording a
   multi-task, multi-epic burst in a single day. Nothing inspected looks rushed — the 20-run
   reproducibility test and the promotion-order semantic checks in `build_scenario.py` are the kind
   of thing that's easy to skip under time pressure and wasn't skipped — but E8 (thesis writing)
   is still 0/8 and concentrated in a two-week window at the very end of the plan (8–18 Feb). A
   pace this front-loaded is good for de-risking the engineering epics; it says nothing about
   whether the writing epic gets the same treatment when its turn comes.
